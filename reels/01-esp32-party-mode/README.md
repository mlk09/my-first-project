# Reel #01: "1 TAP = PARTY MODE" (rendered, 20 s)

**Video:** `output/MLexplorer-Reel01-PartyMode.mp4` (1080×1920, 9:16, 30 fps, 20.2 s, H.264 + AAC, -14 LUFS, Hinglish voice-over)
**Cover:** `output/cover.jpg`

This is an **animated explainer**. Everything is drawn by `build_reel.py`: the ESP32, the LED strip, the phone app, the wiring, the captions, the music and the sound effects. The voice is generated by `make_voice.py`. No stock footage, no third-party music and nothing from the reference video is used, so there are no copyright risks. It is not footage of real hardware.

It is an AI-synthesised voice. Your own recorded voice will usually feel more personal and trustworthy for a brand. To swap it in, record the lines above at the same times and rebuild:

```bash
pip install numpy scipy opencv-python-headless pillow kokoro-onnx soundfile
```
