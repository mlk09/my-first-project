## 3. Using your own voice (recommended)

The AI voice works, but your own voice builds trust and makes the page feel personal. Record the lines above in the same time slots (phone voice memo is fine, in a quiet room), save each one as `work/vo_<key>.wav` (keys: `hook ask drop def simple uses best python end`) and rebuild. Each line is sped up automatically if it runs too long for its slot.

## 4. Rebuild

```bash
pip install numpy scipy opencv-python-headless pillow soundfile kokoro-onnx
# AI voice: download kokoro-v1.0.int8.onnx + voices-v1.0.bin first (see make_voice.py)
python3 pathshala/ep01-python-kya-hai/make_voice.py --models <dir>
python3 pathshala/ep01-python-kya-hai/build_short.py --preview   # 24 stills -> work/preview.jpg
python3 pathshala/ep01-python-kya-hai/build_short.py             # full video, about 1–2 min
```
To make the next episode, copy this folder and change `LINES` (make_voice.py), `VO`/`CAPS` and the scene functions (build_short.py).
