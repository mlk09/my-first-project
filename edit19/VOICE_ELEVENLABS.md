# EP 12 for loop + range(): ElevenLabs voice-over script

**Recommended settings:**
- **Model:** Eleven Multilingual v2, or Eleven v3 for more expression.
- **Voice:** a young, energetic Hindi/Indian-English male or female voice.
- **Stability** 40–45 %, **Similarity** 75 %, **Style** 25–35 %, **Speaker boost** on, **Speed** 1.05–1.1.

**Why Devanagari:** Hindi in Devanagari gets the most natural accent. Technical words (for loop, range, print, start, stop, step) stay in English letters so they're pronounced the English way. Numbers inside code are written as words so they're read correctly.

## Option B: one continuous take

Generate it once and line it up with the video. The `...` adds a short pause.

```

Like, share और subscribe करो! अगला episode: break और continue!
```

## Option C: Roman Hinglish (if your voice reads Roman better)

```
Ek se das tak ginti? Sirf do lines mein! For loop!
Socho, menu mein chai, poha aur vada hai. For loop har item ko ek-ek karke uthata hai. Pehle chai... phir poha... phir vada. Har item ke liye loop ek baar chala!
Ab range: for i in range, ek comma chhe. Ek hai start... aur chhe hai stop. Run karo! Ek, do, teen, chaar, paanch... Arre! Chhe nahi aaya? Kyunki range mein last number shaamil nahi hota!
Range paanch likho, toh shuruaat zero se hogi: zero, ek, do, teen, chaar. Aur teesra number hai step. Range zero, das, do... matlab do-do ka jump: zero, do, chaar, chhe, aath. Save kar lo!
Ab ek tricky sawaal! Range do, das, teen... kya print hoga? A, B ya C? Comment karo!
Sahi jawaab hai A: do, paanch, aath! Gyaarah nahi aayega, kyunki das se pehle rukna hai.
Like, share aur subscribe karo! Agla episode: break aur continue!
```
