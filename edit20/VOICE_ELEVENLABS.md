# EP 13 break, continue, pass: ElevenLabs voice-over script

**Model:** **Eleven Multilingual v2**. The `<break time="…" />` tags are silent pauses that keep the voice in sync with the scenes. With Eleven v3, delete the tags and keep the `...`.

**Settings:** Stability 40–45 %, Similarity 75 %, Style 30 %, Speaker boost on, Speed 1.05–1.1.

## Paste all of this at once (one generation)

```
break, continue और pass! Loop का remote control, सिर्फ़ तीन words में! <break time="0.5s" />
पहला: break. मतलब... loop ख़त्म! <break time="0.8s" />
देखो: एक से दस तक loop चल रहा है. अगर num पाँच हुआ, तो break. <break time="0.6s" />
एक, दो, तीन, चार... और पाँच आते ही, धड़ाम! Loop वहीं ख़त्म. बाकी numbers कभी नहीं चलेंगे. <break time="1s" />
दूसरा: continue. सिर्फ़ एक step skip! <break time="0.5s" />
अगर num तीन हुआ, तो continue. देखो... <break time="0.8s" />
एक, दो... तीन को jump! फिर चार, पाँच. Loop चलता रहता है, बस वो एक round skip होता है. <break time="1s" />
तीसरा: pass. मतलब... कुछ नहीं करो! <break time="0.5s" />
जब वहाँ code लिखना ज़रूरी हो, पर काम कुछ नहीं, तो pass लिखो. देखो, दो भी print हुआ! <break time="1s" />
याद रखो: break मतलब loop ख़त्म. continue मतलब एक round skip. और pass मतलब कुछ नहीं. Save कर लो! <break time="0.8s" />
अब tricky सवाल! इस code का output क्या होगा? A, B या C? Comment करो! <break time="3s" />

Like, share और subscribe करो! अगला episode: Strings!
```
